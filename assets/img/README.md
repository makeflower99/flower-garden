# assets/img/

- `favicon.svg` — makeflower 모티프의 미니멀 라인아트 꽃 아이콘. 브라우저 탭 아이콘 + 헤더 로고 마크로 사용. 공개 템플릿에 포함되는 파일입니다.
- `avatar-placeholder.svg` — 프로필 사진을 아직 넣지 않았을 때 보여줄 원형 placeholder. 공개 템플릿에 포함되는 파일입니다.
- `private/` — 실제 프로필 사진을 넣는 곳. `.gitignore`에 등록돼 있어 커밋되지 않습니다. 사진을 넣은 뒤 `data/profile.json`(개인 데이터)의 `photo` 경로를 `assets/img/private/파일명`으로 지정하세요. 자세한 절차는 `CONTENT_GUIDE.md`의 "처음 시작하기" 참고.
